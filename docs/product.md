# Product · Treasure

> *a private cabinet of things owned, used, & remembered*

## 一句话

**Treasure 让一个有多个爱好的人，把"我拥有过的物件"用图鉴的方式记下来 —— 不是冷冰冰的清单，是一座私人的小博物馆。**

## 灵感来源

来自原型对话（[`../prototype/chats/chat1.md`](../prototype/chats/chat1.md)）：

> "我是个羽毛球爱好者、摄影爱好者、骑行爱好者...每个领域都会有一些装备。有时候我还希望记录我开过什么车（因为经常租车出去玩）。所以，如果有一个 app 能够记录我拥有过的物件（球拍、摄影设备、自行车...)，记录他们的样貌、参数、历史...那将会非常酷。"

> "我希望这个 app 能够简单地满足我对我爱好领域的装备的拥有感，不需要太复杂的交互，录入方式不要是机械的填表格。"

## 谁会用

一个 25–45 岁、有可支配收入、有一两个深度爱好的成年人。他/她：

- 已经在用别的工具拍照、记账、写日记，但**没有一个东西能把"物件本身的故事"装进去**
- 在意"拥有"这件事的仪式感（开箱、配色、版本号、序列号、改装史）
- 不希望被动填表，但愿意为一件喜欢的东西**多花两分钟把它记好看**

## 它是什么

一个手机上的"图鉴"。每件物品有：

- **一张矢量图**（博物馆线描风，统一插画语言）
- **顶部 hero specs**：4–6 个最关键的参数（重量、光圈、动力、屏幕……）
- **完整 specs**：余下的细节
- **history**：一条时间线 —— 购入、第一次比赛、换线、改装、出手……
- **album**：用户上传的真实照片
- **状态**：拥有 / 转让 / 租赁

## 信息架构

四个一级品类（**rooms**）来自原型：

| ID | 中文 | 英文 | 备注 |
|---|---|---|---|
| `badminton` | 羽毛球 | Badminton | |
| `photo` | 摄影 | Photography | 含相机、镜头、三脚架 |
| `cars` | 汽车 | Cars | **租车记录**也算 |
| `tech` | 电子产品 | Tech | |
| `coffee` | 咖啡 | Coffee | cycle 0011 加入 |
| `wine` | 酒水 | Wine | cycle 0011 加入 |

设计成品类是**用户可扩展**的 —— cycle 0026 起的 `category_prefs` 表把内建与用户自定义并到同一份模型；cycle 0027 起自定义分类真正能装物品。Portal 上的"门"会按用户的可见性偏好显示／隐藏。

## 核心设计原则

1. **拥有感 > 完整性**。宁可信息少而美，不要逼用户填满所有字段。
2. **录入不能像填表**。chat-first 是默认入口 —— 拍照 / 录音 / 粘 URL / 打字都行；AI 做结构化提取，用户对每张草稿卡决定接受还是丢。
3. **统一的视觉语言**。所有 hero 图都是博物馆线描风（或用户从相册挑的代表图），不允许第三方 social-style 杂乱缩略图。
4. **本地优先**。东西是你的，数据应该首先属于你的设备。BYO-key 直连 AI 模型厂商，不走代理；云端同步是可选项，不是前提。

## 不做什么

为了让 Treasure 是 Treasure，不是别的：

- ❌ **不是社交平台**。没有 feed、没有点赞、没有关注。一个人的图鉴。
- ❌ **不是二手交易**。可以记录"已转让 / 出手价"，但不接入交易市场。
- ❌ **不是装备评测**。不抓取参数库、不做对比表。每件物品的参数由用户/AI 填进去就够了。
- ❌ **不是相册**。真实照片是某件物品的附属，不是首屏内容。

## 用户故事

v1.0 已经覆盖：

- *作为用户，我打开 app 看到的是一个有仪式感的门厅，而不是一堆乱七八糟的入口。*
- *作为用户，我点 "羽毛球" 这扇门，能看到我拥有过的所有球拍。*
- *作为用户，我点一个球拍，能看到它的样子（线描矢量图）和最关键的几个参数；上滑看全部 specs / 历史 / 影集；翻面看自己拍的实拍。*
- *作为用户，我新增一件物品 —— 拍几张照片 + 录一段语音 + 打几个字 → AI 一次能识别多件，按 photo_assignments 自动把图分给具体物品。*
- *作为用户，我对某件已收入的物品说"颜色是红色" → AI 返回增量改动，原物品的影集不丢。*
- *作为用户，我配置了我自己的 Anthropic / OpenAI / Kimi key —— 多份并存，录入页 chip 临时切换本会话用谁。*
- *作为用户，自定义"图书"分类并挑一张代表图，AI 之后会把书录入这个分类。*
- *作为用户，长按图鉴里的物品进入编辑态、批量删除或拖动调序；拖到屏幕上下边缘还能滚列表。*
- *作为用户，关掉 app 再打开，我刚加的那件东西还在 —— 因为是本地优先（Room）。*
